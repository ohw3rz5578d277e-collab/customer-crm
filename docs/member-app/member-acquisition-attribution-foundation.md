# Member acquisition attribution foundation

Public new registration is also a lead-acquisition channel. Attribution must support later analysis of:

Instagram / website / paid or organic source -> FAMILY PASS registration -> inquiry -> reservation -> shoot -> repeat.

Acquisition fields and UTM/referrer data are analytics metadata only. They are never identity authority and may not select, merge, or overwrite a Customer/Prospect.

Registration attribution is append-only and remains associated with stable Member Identity through Prospect -> Customer promotion.

Funnel events are append-only. Reservation/shoot/repeat events require reservation context. A later integration may connect this model to the existing Meta/LINE attribution infrastructure, but this phase performs no such connection.

No Production analytics write, ad-platform call, CRM/Google/D1 mutation, Customer ID generation, LINE send, deploy, migration, route/secret/R2/UI change, automatic benefit/commerce action, BLACK/MEMORY write, or paid spend is authorized.
