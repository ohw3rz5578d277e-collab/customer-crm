# MIZUNO PHOTO MEMBER — Production Entry Default-Off Patch Manifest

Baseline policy: 2026-09-25 JST

## Purpose

This manifest protects a future default-off Production Worker entry patch without creating a self-invalidating main-SHA cycle.

It does **not** modify the Production Worker entry.

## Fresh main gate instead of static main pin

A Git commit changes every time this manifest itself is merged. Therefore a hard-coded canonical main SHA inside the manifest becomes stale immediately after merge.

The corrected contract is:

1. fresh-read the canonical main SHA immediately before generating the Production entry patch;
2. pass that SHA as both the observed current main and the expected authorized baseline;
3. require an exact 40-character SHA match;
4. separately require the exact Production entry Git blob SHA.

The manifest no longer hard-codes a main SHA.

At the time this correction was prepared, the observed canonical main was:

`f6ef8e120af73353b4310cea23921f734aecd2e1`

That value is audit context only, not a permanent manifest baseline.

- Production entry Git blob SHA: `9791174a5be2aa8861134f6881e2cee451f50966`

## Exact candidate rule

The future Production entry patch must be generated by:

`buildMemberProductionDefaultOffWiringCandidate(current_exact_entry_source)`

and must pass:

`inspectMemberProductionCandidate(candidate_source)`

No manual edit is allowed after generation.

## Default-off properties

The frozen candidate contract still requires:

- `MEMBER_PRODUCTION_OWNER_APPROVED=false`
- Member route mode separately requires `MEMBER_PRODUCTION_ROUTE_MODE=enabled`
- LINE Login external exchange approval remains `false`
- public asset adapter remains `null`
- private media storage adapter remains `null`
- LINE callback exception is exact GET only
- callback exception exists only when Owner flag and route mode are both active
- Member dispatch remains after the global Production boundary
- existing CRM dispatch remains the fallback

Therefore importing the candidate alone does not activate customer-facing Member routes.
